# Задача 2. Работа с кастомными полями amoCRM

## Описание

После этого надо выгрузить из amo кастомные поля и проверить, есть ли там нужные нам, все поля которых нет, надо создать, затем сохранить все нужные нам поля в базу данных и сохранить связь с моделью Аккаунт в базе данных, т.к. у каждого аккаунта свои id кастомных полей.

“Контакт” должен иметь кастомные поля:
Дата рождения (тип поля в amo “Дата”)
Возраст (тип поля в amo “Число”)
Лазерное омоложение лица (тип поля в amo “Число”)
Ультразвуковой лифтинг (тип поля в amo “Число”)
Лазерное удаление сосудов (тип поля в amo “Число”)
Коррекция мимических морщин (тип поля в amo “Число”)
Лазерная эпиляция (тип поля в amo “Число”)

“Сделка” должна иметь кастомные поля:
Услуги (тип поля в amo “Мультисписок”)
Бюджет (стандартное поле amo, тип “Число”)


| Property | Description |
|----------|-------------|
| `fieldType` | содержит тип поля в amo |
| `fieldId` | содержит id поля в amo |
| `fieldName` | уникальное, названия указываются в проекте в константах, по названиям и типу мы проверяем, наличие нужных полей в amo, а также название нужно чтобы достать поле из базы|
| `accountId` | id аккаунта в нашей базе|
