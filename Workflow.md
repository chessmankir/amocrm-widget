# Workflow

## Переменные окружения

| Название          | Тип данных | Описание                                                |
| ----------------- | ---------- |---------------------------------------------------------|
| AMO_CLIENT_ID     | string     | Client ID интеграции amoCRM                             |
| AMO_CLIENT_SECRET | string     | Секретный ключ интеграции amoCRM                        |
| AMO_REDIRECT_URI  | string     | URL для получения OAuth-кода после установки интеграции |
| POSTGRES_HOST     | string     | Хост PostgreSQL                                         |
| POSTGRES_PORT     | number     | Порт PostgreSQL                                         |
| POSTGRES_USER     | string     | Пользователь PostgreSQL                                 |
| POSTGRES_PASSWORD | string     | Пароль пользователя PostgreSQL                          |
| POSTGRES_DB       | string     | Название базы данных PostgreSQL                         |
